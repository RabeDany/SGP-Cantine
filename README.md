# SGP-Cantine

Système de Gestion des Stocks et de la Planification des Repas pour Cantines Scolaires Communautaires — Madagascar (Androy / Anosy).

## MVP actuel

Frontend Vue 3 avec **données mock** et persistance localStorage — couvre les 11 user stories P1 du sprint MVP (18 juillet 2026).

Voir [`frontend/README.md`](frontend/README.md) pour le démarrage et les comptes démo.

```bash
cd frontend
npm install
npm run dev
```
